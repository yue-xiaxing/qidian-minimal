========================================================================
 起点极简 · Qidian Minimal  v1.10.0
 安装说明（Microsoft Edge / Google Chrome 通用）
========================================================================

一、它能做什么
------------------------------------------------------------------------
  1. 把起点中文网的浏览页改成现代几何极简风：发丝线分层、统一圆角、
     单一强调色、系统字体、8px 间距节奏。
  2. 「圆弧外框」统一风格：每一个可按按键、每一本书都是
     12px 圆角 + 1px 纤细线。
       夜间框内 #171C20，框线 #303539，文字 #BEC8D2
       日间框内 #FFFFFF，框线 #E4E7EC，文字 #15171C
     覆盖：首页书单三栏、榜单、带封面的书卡、限时免费、编辑推荐、
     以及全部作品页（/all/）左侧七组筛选项与右侧两列书单。
  3. 日间 / 夜间 / 跟随系统三档配色，随时切换，不重载页面、不打断你。
     夜间页面底色为「偏紫的近黑」（#0b0910），框内为 #171C20。
  4. 个人中心（my.qidian.com：书架 / 消息中心 / 用户等级 / 财务中心 /
     票夹 / 红包 / 书评 / 本章说 / 徽章 …）在夜间会自动适配：
     站点写死的白色卡片、表格、**弹窗**、侧栏选中项都会被换成深色表面，
     上面的深色文字（含暗色链接）会自动提亮，保证看得清；
     站点自带的深色顶栏与浅蓝/浅红等彩色块不会被误伤。
  5. **书架会显示封面**：每本书左侧补一张 40×53 的圆角封面（仅书架页）。
  6. 移除页游入口：顶部那条「随机广告 · 页游」广告带整条消失（不留空白），
     主导航里的「页游」入口也一并移除。可一键恢复。
  7. 优化排版：主导航由深灰底白字改成浅色条 + 悬停强调线。
  8. 可选隐藏推广位（默认关闭，需要时在弹窗里打开）。
  9. 夜间「横扫大面积亮色」：站点用浅色高亮表示选中（比如书架的勾选行）时，
     会被统一改成暗色选中 + 左侧强调色竖条；顶部「编辑推荐 / 游戏推荐」
     里的"游戏推荐"标签页会被移除。
 10. 全站字体可读性：凡是「暗底 + 暗字」都会自动提亮，包括左侧未选中栏目、
     底部「全选 / 置顶 / 移动至 / 删除」操作条、页脚「阅文集团旗下平台」链接。

  重要：阅读页（正文页）不做任何改动。
        */chapter/* 、read.qidian.com 、vipreader.qidian.com 完全不受影响。


二、生效范围
------------------------------------------------------------------------
  完整优化    www.qidian.com / qidian.com
  基础优化    my.qidian.com（个人中心、书架）、free.、all.、so. 等子域
              —— 配色、字体、表格发丝线、控件圆角、夜间模式都会生效，
                 但页面上特有的模块需要你导出结构后才能做精确优化（见第五节）
  完全不注入  */chapter/*、read.、vipreader.（阅读页）
              passport.、ptlogin.、pay.（登录与支付）
              m.qidian.com（移动端模板）
  固定日间    www.qidian.com/book/{id}/（书籍详情页）
              —— 该页是站点另一套浅色玻璃拟态模板，夜间在那一页必然半黑半白，
                 所以这一页固定日间（v1.7.0 起已并入夜间，可正常切换）：
                 工具栏角标会显示「日间」，弹窗里也会写明。


三、安装步骤（Edge）
------------------------------------------------------------------------
  1. 解压本扩展到一个固定目录，例如：
         D:\APP_EN\DSH\qidian-minimal
     注意：目录里要能直接看到 manifest.json，不要多套一层文件夹。

  2. 打开 Edge，地址栏输入：
         edge://extensions/
     回车。

  3. 打开左下角的「开发人员模式」开关。

  4. 点击「加载解压缩的扩展」。

  5. 在弹出的目录选择框里选中 qidian-minimal 这一层目录，确定。

  6. 列表中出现「起点极简 · Qidian Minimal」即安装成功。
     建议点击工具栏的拼图图标，把它固定到工具栏，方便查看状态。

  Chrome 用户：第 2 步改为 chrome://extensions/ ，其余完全一致。

  升级提示：从旧版本升级时，装好后请在 edge://extensions/ 点一次「重新加载」，
            然后刷新起点页面。


四、使用方法
------------------------------------------------------------------------
  · 悬浮按钮：打开起点后，页面右下角会出现一个方形按钮（在站点右下角
              「我的书架 / 回到顶部」那一条的正下方，不会挡住它们），
              点击即可在日间 / 夜间之间切换。
  · 切换方式： 点页面右下角悬浮按钮，或点浏览器工具栏的扩展图标（弹窗里三档可选）。
              想改键：edge://extensions/shortcuts
  · 工具栏图标：
        角标 ON    -> 当前页面已应用极简样式
        角标 跳过  -> 当前是阅读页，扩展主动让路（这是正常的，不是故障）
        无角标     -> 当前不是起点页面
  · 点击工具栏图标打开设置面板：
        启用极简界面 / 配色主题（日间·夜间·跟随系统）
        移除页游入口 / 隐藏推广位（默认关）/ 悬浮日夜按钮
        以及底部的「导出当前页结构」（见第五节）


五、某个页面没被优化怎么办（导出当前页结构）
------------------------------------------------------------------------
  弹窗底部有「导出当前页结构」按钮：
    1. 在没被优化的页面（例如书架页）打开扩展弹窗；
    2. 点「导出当前页结构」；
    3. 页面 DOM 轮廓（标签 + id + class）会复制到剪贴板，同时显示在下方的
       文本框里（若没自动复制，在文本框里按 Ctrl+C 即可）；
    4. 把内容发给扩展作者，就能给这个页面补上精确的优化规则。

  说明：导出只包含元素标签与 class/id 名称，不含书评、正文等任何文本内容。


六、常见问题
------------------------------------------------------------------------
  Q1. 装完打开起点，导航条是浅色的、字也正常吗？
      A. v1.1.0 已修复 v1.0.0 的问题（当时主导航被染成深灰导致字看不见、
         首页书单被误改成网格导致大片空白）。若你看到的仍是旧样子，
         请在 edge://extensions/ 里点「重新加载」并刷新页面。

  Q2. 打开正文页会不会被改？
      A. 不会。阅读页在清单层就被排除，脚本和样式都不会注入；
         即便站内跳转进阅读页，脚本也会立即自我卸载并清除所有痕迹。

  Q2b. 之前顶部「起点中文网」那行左右两侧有黑块，现在还有吗？
      A. v1.3.1 已修复。原因是那一行在站点里实际只有 1200px 宽，底色只铺了中间；
         现在改成整行铺满（元素底色 + 全出血阴影 + 裁切），日间与夜间两侧都一致。
         若你看到的仍是旧样子，请在 edge://extensions/ 点「重新加载」并刷新页面。

  Q2c. 书籍详情页为什么切不到夜间？
      A. v1.4.0 起详情页固定日间（设计如此）。那一页是站点另一套浅色玻璃拟态模板，
         首屏的浅色底来自负层级装饰层，套夜间会出现上黑下白。该页日间样式照常优化，
         只是不提供夜间。工具栏角标会显示「日间」。

  Q3. 书架页（my.qidian.com）只变了一半？
      A. v1.5.0 起书架等个人中心页面已做**运行时自适应**：白色卡片/表格/弹窗/选中项
         在夜间都会自动转成深色表面并提亮文字，书架每本书还会补上封面。
         若仍有个别模块没被适配，用第五节导出结构后可以做精确版。

  Q3b. 书架的书为什么多了封面图？会不会拖慢加载？
      A. 封面来自起点自己的图床（规律实抓验证过），按行懒加载（loading=lazy），
         取不到图会自动移除占位，不会留破图。只在书架路径生效。

  Q4. 顶部那条页游广告带不见了，会不会留下空白？
      A. 不会。v1.1.0 是整块隐藏（老版本只藏了里面的链接，会留下空白带），
         所以在设置面板里关掉「移除页游入口」，它也会完整回来。

  Q5. 想彻底停用？
      A. 设置面板关掉「启用极简界面」，页面立刻恢复起点原样；
         或在 edge://extensions/ 里禁用/移除本扩展。

  Q6. 提示「清单文件缺失或不可读」？
      A. 多半是选错了目录层级。请确认所选目录内直接存在 manifest.json。


七、隐私
------------------------------------------------------------------------
  权限只有两个：storage（保存你的开关偏好）与 clipboardWrite（仅在你点击
  「导出当前页结构」时写入剪贴板）。不发起任何网络请求，不采集、不上报任何数据，
  不读取页面正文内容。全部代码可在 src/ 与 popup/ 目录内直接查看。


八、卸载
------------------------------------------------------------------------
  edge://extensions/ -> 找到「起点极简」-> 点击「移除」。
  扩展写入页面的 localStorage 键为 qd_minimal_cfg（仅保存你的开关偏好），
  在设备上清除站点数据即可一并删除。
